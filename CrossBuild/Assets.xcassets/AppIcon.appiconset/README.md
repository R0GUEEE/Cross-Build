# AppIcon placeholder

`AppIcon.png` here is an auto-generated placeholder (dark background, "CB" monogram) so
the app doesn't ship with a blank home-screen icon. Regenerate it with `make_icon.py`
(requires Pillow) or replace `AppIcon.png` with real 1024x1024 artwork before any
real release. `make_icon.py` is excluded from the Xcode target in `project.yml` and is
not bundled into the app.
